# clawchat/

这个项目作为一个 ClawChat agent 运行时的**可版本化配置**（由 ClawChat 桌面端生成）。

**它是明文目录，不是隐藏的点目录** —— 这里面是你的资产：你写的人设，以及 agent
攒下来的记忆。藏起来你就不会去看、不会去改、也不会记得备份它。

| 路径 | 归谁 | 更新方式 |
|---|---|---|
| `agent.md` | **你** | 只创建一次，我们永不改写。改它就是改 agent 性格 |
| `memory/owner.md` `users/` `groups/` | **你 / agent** | 同上。agent 自己维护 |
| `memory/conversations/` | **ClawChat** | 对话原文 + 收发过的文件，**每轮自动追加**。这是 agent 记忆的底层 |
| `skills/clawchat-*` | **ClawChat** | 描述的是我们提供的能力面，**每次启动按当前版本刷新** |
| `skills/` 下其它名字 | **你** | 自己加的技能，我们永不触碰 |

`skills/clawchat-*` 之所以归我们刷新：它描述的是随 app 版本变化的能力面。写一次就不管，
会让早期建的项目永远学不到后来才有的能力，还照着一个已经变了的界面行事。

`memory/conversations/` 是 agent 真正的记忆：一个对话一个目录、按月分片，收发过的文件
存在各自的 `files/` 下。**删掉它 agent 就真的忘了**——正文不在别处留副本。

**凭据不在这里。** 但 `memory/` 里有关于具体人的私人信息，以及逐字的聊天记录，所以我们
生成了一份 `.gitignore` 把整个 `memory/` 排掉 —— 默认不进版本库。想让它进（比如只有你
自己用的私有仓库），删掉那一行即可；那份文件我们只创建一次，之后不再碰。
